# Giant Golem 技能时序与起始参数

体型：模型原始包围盒高度 1.8805 米，项目内统一缩放为 2.3398，目标高度 4.4 米。感知、NavMesh 和程序移动使用稳定的 Boss 根节点；旋转与腾空姿态由子模型动画表现。

测量依据：`GiantGolem_AnimationMeasurements.json`。十个原地动画各采样 100 个归一化时间点，骨骼位置由 Humanoid Playables 实际计算；`GiantGolem_Poses/` 每招另有 12 帧姿态图，按从左到右、从上到下阅读。位置采样精度为动画长度的 1%，不是逐原始动画帧标注。

表内锁定点、出手窗口、位移与后摇是可调的初始玩法配置。踩踏/跳攻释放点依据落脚测量设置；普通攻击窗口还结合了 Play Mode 真实命中检查。技能结束点统一为 0.99，攻击不循环。

左右踩踏的抬脚高度约2米，0.45时仍然抬脚，0.49时足部骨骼已下降到约0.25米的站立高度。跳攻0.51时足部约3米，0.58时左脚约0.55米，0.59时双脚回到约0.32/0.37米。足部骨骼是踝部挂点，不直接当成角色脚底碰撞高度。

投石0.64–0.67为头顶持石与出手准备，0.68右手开始快速下降，0.69–0.70完成甩出。方向和落点在0.60后锁定，飞行中不追踪玩家。当前生成的是功能用球形石头和碎石粒子，未制作手持石头的拾起道具表现。

冲刺位移窗口0.27–0.56，速度10 m/s，距离上限为提交时目标距离减1.8米；旋转位移窗口0.25–0.76，速度6 m/s，距离上限为提交时目标距离加2米。两者均按 NavMesh 边界和胶囊扫掠检查障碍，受阻提前停位移，动画继续收招。旋转同目标每次技能仅结算一次。

地波要求目标脚底距离所站地面不超过0.55米，且目标地面高度与脉冲地面接近；短暂离地或下台阶不能自动免伤。最终扣血仍经过现有 PlayerHealth，无敌帧正常生效。圆环在落地时显示实际伤害半径，持续0.7秒，属于瞬时伤害提示。

近距类别边界3.2米，快跑停在约2.3米附近；普通动作使用真实手部命中体，玩家可以通过距离与侧向移动使攻击落空。2.2米正面站立目标的四个动作均已在 Play Mode 命中一次；距离边缘与移动目标的最终手感仍需试玩调整。

普通攻击共享2.5秒冷却；左右踩踏共享7秒；冲刺9秒、旋转11秒、跳攻12秒、投石10秒。默认收招后额外间隔0.55秒，跳攻0.85秒。冷却从技能提交计算，后摇与动画收招独立，所有数值在对应 `BossSkillData` 中调整。
